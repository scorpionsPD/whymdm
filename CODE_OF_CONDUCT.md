# Code of conduct

WhyMDM is a small, friendly reference project. Everyone who takes part (in issues, pull requests or anywhere else the project is discussed) is expected to:

- be respectful and patient, especially with people who are new to MDM or to open source;
- give credit, and assume good intent;
- keep criticism about the work, not the person;
- keep it free of advertising: mention products only when it helps explain a code.

Harassment, personal attacks, discriminatory language and sharing other people's private information aren't acceptable. The maintainer may edit or remove contributions that break these rules, and may block people who repeatedly do so.

To report a problem, open a confidential security advisory on GitHub or contact the maintainer through the email on their GitHub profile.
